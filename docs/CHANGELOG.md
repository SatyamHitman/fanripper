# Changelog

## 0.1.59
- **Fanfix support** (Max and Lifetime) — a save button on photos and videos in
  posts, chats, the Gallery and replays, plus whole-creator, chat
  and Gallery backups. Videos at the quality Fanfix stores; DRM handled on your
  device.
- **Dark mode** — Settings → Appearance: Light, Dark or Match my computer.
- **Section folders for single saves** — single saves and Download all land in
  the same section folder (Timeline, Messages, Paid…) a whole-profile backup
  uses.

## 0.1.30
- **Embedded metadata** — creator, caption, PPV price and original post date are
  written into each downloaded file's own metadata.
- **Richer delivery captions** — the post / chat text now travels with the file.
- **Faster, more reliable bulk** — parallel download engine, auto-resume after a
  crash, and an instant Stop.
- **Large-file + cloud reliability** — fixes for multi-gigabyte DRM videos and
  cloud backup.

Every release is on the [Releases page](../../releases) and at
https://install.fanripper.com. Fanripper tells you when a new version ships.
