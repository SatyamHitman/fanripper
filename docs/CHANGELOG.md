# Changelog

## 0.1.62
- **Every Save in a DM, at once** — a message with many photos and videos shows
  a Save for each video and Download all straight away, no swiping.
- **Voice notes** between photos in a chat get their own Save again.
- **JustForFans** — a post that had lost its Save button gets it back.
- **Phone app** — a download that isn't the real file is caught and offered
  again; copying to your chosen folder goes one file at a time and a failed
  copy shows Try again.

## 0.1.61
- **Less room for long videos** — protected videos need about a third less
  space in Chrome while they download, and temporary files are cleared after
  every download.
- **Chrome storage limits explained** — if Chrome's "delete site data when you
  close all windows" setting limits Fanripper, the message says so and opens
  the setting. "Clear temporary files" frees space in one press, and a backup
  waits instead of failing when Chrome is full.
- **Faster Fanfix** — Gallery videos start sooner; a video Fanfix has no file
  for says so instead of asking you to retry.
- **JustForFans in the phone app** — Save buttons on posts, and a photo post
  saves every photo.

## 0.1.60
- **Saved stays Saved** — a finished download keeps saying "Saved", and a file
  you saved before tells you so.
- **Video length on the button** — tell a short preview from the full video.
- **Voice notes in OnlyFans DMs** get a Save button.
- **Paid messages** saved from the chat go in the Paid folder.
- **Fanfix** downloads stop when you switch accounts; incognito downloads and
  cloud backups stay separate from normal windows.

## 0.1.59
- **Fanfix support** (Max and Lifetime) — a save button on photos and videos in
  posts, chats, the Gallery and replays, plus whole-creator, chat
  and Gallery backups. Videos at the quality Fanfix stores; DRM handled on your
  device.
- **Dark mode** — Settings → Appearance: Light, Dark or Match my computer.
- **Section folders for single saves** — single saves and Download all land in
  the same section folder (Timeline, Messages, Paid…) a whole-profile backup
  uses.

## 0.1.30
- **Embedded metadata** — creator, caption, PPV price and original post date are
  written into each downloaded file's own metadata.
- **Richer delivery captions** — the post / chat text now travels with the file.
- **Faster, more reliable bulk** — parallel download engine, auto-resume after a
  crash, and an instant Stop.
- **Large-file + cloud reliability** — fixes for multi-gigabyte DRM videos and
  cloud backup.

Every release is on the [Releases page](../../releases) and at
https://install.fanripper.com. Fanripper tells you when a new version ships.
